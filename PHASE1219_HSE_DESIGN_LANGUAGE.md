# PHASE 1219 — HSE Design Language Specification

## Principles
1. **Human-Centered Vocabulary**: Use human engineering terms (`Open Project`, `New Project`, `Recent Projects`, `Save`, `Scene`, `Objects`) rather than machine internal terms (`ENGINE_HOME`, `PROJECT_BROWSER`, `PRIMEGATE`).
2. **Recognition Over Recall**: Display project cards with metadata (primitive count, category, last opened, path) instead of numeric prompts.
3. **Hardware-Aware Rendering**: Low-overhead OpenGL 3.3 rendering tailored to Intel Pentium 4425Y & Intel UHD 615 GPU.
4. **Progressive Disclosure**: Show key project actions immediately; reveal deep physics/harmonic properties inside runtime upon request.

## Color Palette & Visual System
- **Background**: `#14171F` (Deep Slate)
- **Surface / Card**: `#1E222D` (Bordered Slate)
- **Primary Accent**: `#3B82F6` (Electric Blue)
- **Success / Status**: `#10B981` (Emerald)
- **Text Primary**: `#F3F4F6` (Bright Slate)
- **Text Muted**: `#9CA3AF` (Muted Gray)

## Typography & Spacing
- Monospace / Standard Grid, 8px spacing system, structured box borders (`┌─┬─┐`, `│ │`, `└─┴─┘`).
