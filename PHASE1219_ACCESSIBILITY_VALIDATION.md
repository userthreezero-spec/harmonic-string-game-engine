# PHASE 1219 — Accessibility Validation

## Keyboard Navigation & Focus
- **Tab Key**: Toggles mouse capture mode in 3D runtime.
- **Enter Key**: Opens selected/recent project in Project Hub.
- **Number Keys (1-9)**: Direct card selection in Project Hub.
- **N / C Keys**: Triggers New Project creation.
- **A Key**: Opens WebOS AI Assistant surface information.
- **ESC / Q Keys**: Context-aware back/exit (ESC in runtime returns to Hub; ESC in Hub exits application).

## Visual Contrast & Readability
- Dark theme background (`#14171F`) with high-contrast bright text (`#F3F4F6`) exceeding WCAG AAA contrast ratio (> 7:1).
- Card borders (`#1E222D`) visually delineate project boundaries.
